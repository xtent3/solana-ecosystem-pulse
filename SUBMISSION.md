## Submission text

Solana Ecosystem Pulse is a reproducible reporting pipeline that collects live Solana mainnet health directly from JSON-RPC and combines it with public CoinGecko and DeFiLlama ecosystem data. One timestamped snapshot produces machine-readable JSON, a human-readable Markdown report, and a responsive self-contained HTML dashboard.

The implementation requires Python 3.11 only: no API keys and no third-party runtime packages. It reports slot/epoch progress, observed TPS, validator and delinquent-stake health, SOL supply, price, DeFi TVL, stablecoin supply, and DEX volume. Each economic endpoint has independent health reporting, so a partial API outage is visible and never silently converted to zero. Threshold alerts are deterministic and explainable.

The repository includes an 18-test suite, HTML escaping for untrusted source text, atomic output writes, a six-hour GitHub Actions refresh workflow, current sample artifacts, architecture/data-source documentation, and a one-command local run:

`python -m solpulse --output output`
